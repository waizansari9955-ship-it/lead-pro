# LeadPro - AI Lead Generation & CRM Platform

LeadPro is a full-featured Django web application integrated with Firebase Firestore for real-time lead extraction, client requirement analysis, sales pitch generation, and lead pipeline CRM management.

## 🚀 Features
- **AI Lead Finder Tool**: Search & extract verified leads with addresses, phone numbers, and client intent signals.
- **Client Requirement Analysis**: Automatically identifies client needs based on industry/niche.
- **AI Pitch Generator**: 1-click customized cold email/pitch script creation with copy & mail options.
- **Kanban CRM Board**: Real-time sales pipeline board with status stages (New, Contacted, In Discussion, Closed Won).
- **Firebase Firestore Integration**: Synchronizes organic leads and extracted database leads in real-time.

## 🛠 Tech Stack
- **Backend**: Python / Django
- **Frontend**: HTML5, Vanilla CSS (Modern Inter Design System), JavaScript (ESModules)
- **Database**: Firebase Firestore SDK
